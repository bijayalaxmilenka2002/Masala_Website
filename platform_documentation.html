1. Executive Summary & Purpose

This report documents the platform upgrade completed for Subhadarshini Agro Pvt Ltd. The previous website (hosted at https://www.subhadarshini.com/gallery.php) was a legacy, static PHP 5.x presentation with non-responsive layouts, fixed package text, and no automated lead processing.

The platform has been redesigned into an E-Commerce Catalog & Real-Time Wholesale Lead Generation System, complete with 1-click WhatsApp ordering, dynamic pack pricing, and a private password-protected Owner Portal for managing customer leads.

2. Legacy Website vs. Modern Platform Comparison

Feature Area Legacy Website (subhadarshini.com) Modern Platform (Vercel Production)
UI & Visual Identity Outdated layout, generic fonts, fixed-width desktop frames. Modernized Saffron & Paprika design system, Outfit & Plus Jakarta Sans fonts.
Device Responsiveness Broken layout on phones; requires horizontal zooming. 100% Mobile First Fluid grids, hamburger drawer, smartphone sticky bottom action bar.
Pack Sizes & Pricing Static descriptive text; customers cannot see pack pricing. Dynamic Engine Real-time switcher (50g, 100g, 250g) with live price updates (e.g. ₹38 vs ₹72).
Ordering Mechanism No instant ordering; required typing phone numbers manually. 1-Click WhatsApp Direct WhatsApp order pre-filled with the exact spice name, weight, and price.
Product Insights Limited static text. Interactive Modal Quick-view popup with health benefits, ingredients, and pack buttons.
Customer Inquiries Generic non-functional form; leads frequently lost. Live Pipeline Assigns tracking ID (#SUB-XXXXXX) with synchronized real-time storage.
Owner Portal / CRM None Leadership had no dashboard to monitor inquiries. Private Portal Authenticated ledger with search, lead status tracker, WhatsApp reply, CSV export.
Hosting & Speed Legacy shared web server with slow load times in India. Edge CDN Vercel Global Serverless Edge Network with sub-second load times.

5. Detailed Breakdown of New Advancements
